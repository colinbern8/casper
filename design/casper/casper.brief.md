# Casper logo and name: art brief

Subject:     Friendly-ghost mark plus "Casper" wordmark for the school IT help desk (formerly "Greg Bot")
Style:       Flat vector, rounded geometry, friendly not childish; Inter-style bold wordmark
Palette:     #1d4ed8 (blue-700, matches app), #ffffff, text uses currentColor
Background:  transparent
Output:      SVG (3 mark concepts: a-ghost, b-bubble, c-badge; each with a lockup)
Size:        64x64 mark, 250x64 lockup
Variants:    3

Provenance: hand-authored SVG. Recraft MCP tools were not available in the session, so this is the fallback lane.
Wordmark is live text; convert to outlines before shipping.
Name rationale: the friendly ghost reads as approachable for students, and "Casper" is short and easy to say and spell.
